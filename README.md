# abidurrahman2025.github.io (classic version)

Portfolio website for **Abidur Rahman** with the original frame layout (menu on the left, content on the right), in a richer color scheme.

## Pages

- `index.html`: frame layout that loads the menu and home page
- `menu.html`: left-hand navigation menu
- `home.html`: welcome page
- `about.html`: background and links
- `resume.html`: education, skills and projects
- `projects.html`: list of all projects
- `project.html`: detailed write-up for each project
- `contact.html`: contact details
- `real_estate_calculator.html`: interactive real estate calculator (standalone app)

## Files

- `styles.css`: shared stylesheet
- `.nojekyll`: tells GitHub Pages to serve files as-is

## Publishing

Upload all files to the root of the `abidurrahman2025.github.io` repository and push to the default branch.
